# All-In-One Esports Discord Bot

A professional, modular, production-ready Discord bot built for Esports organizations.

## Features
- **Esports Management:** Team rosters, scrim tracking, and match reporting.
- **AI Integration:** Powered by OpenRouter for intelligent moderation and support.
- **Security:** Anti-nuke systems and strict permission validation.
- **Community:** Leveling, economy, dynamic voice channels, and tickets.

## Technology Stack
- **Language:** TypeScript
- **Library:** discord.js (v14)
- **Database:** PostgreSQL + Prisma
- **AI:** OpenRouter API
